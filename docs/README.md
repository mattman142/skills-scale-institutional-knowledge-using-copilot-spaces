# OctoAcme Project Management Docs

## Overview
This folder contains OctoAcme's project management process docs. Together, they describe a lightweight lifecycle from initiation and planning through execution, risk management, release, and retrospective improvement. The process emphasizes clear ownership, iterative delivery, quality checks, and consistent stakeholder communication.
